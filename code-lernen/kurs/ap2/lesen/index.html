Fremden Code in der Prüfung lesen und erklären

Ziel dieser Lektion

Du hast ein festes Vorgehen, um unbekannten Code zu verstehen, kannst ihn mit einem Schreibtischtest durchspielen und in einem Satz sagen, was er tut.

Der Stoff

Nicht raten, sondern nachspielen

In der Prüfung steht oft ein Stück Code in Pseudocode, Java oder C#, dazu die Frage „Was gibt das Programm aus?“ oder „Beschreiben Sie die Aufgabe dieser Methode“. Niemand erwartet, dass du das auf einen Blick siehst. Profis lesen Code wie ein Detektiv einen Tatort: erst den Überblick, dann Spur für Spur, und alles wird notiert.

Fünf Schritte, jedes Mal

SchrittWas du tustFrage dahinter
1. ÜberblickNamen von Methode, Parametern und Rückgabetyp lesenWas kommt hinein, was kommt heraus?
2. Variablen sammelnFür jede Variable eine Spalte in einer Tabelle anlegenWas muss ich mir merken?
3. DurchspielenZeile für Zeile ausführen und jede Änderung in die Tabelle schreiben (Schreibtischtest)Welchen Wert hat was, und wann?
4. Grenzen prüfenSchleifengrenzen und Bedingungen genau lesen: < oder <=, beginnt der Index bei 0?Wie oft läuft die Schleife wirklich?
5. In einem SatzDas Ergebnis in eigenen Worten zusammenfassen, ohne den Code nachzuerzählenWozu ist das gut?

Beispiel: Was tut diese Funktion?

Spiel es mit „Ablauf verfolgen“ durch und schreib dabei die Werte von z und ergebnis mit. 3 wird übersprungen, 4 kommt dazu (4), 7 wird übersprungen, 10 kommt dazu (14). Muster, die immer wiederkommen

Viele Prüfungsaufgaben bestehen aus wenigen Grundmustern. Erkennst du sie, ist die halbe Arbeit getan:
- Summieren: Eine Variable startet bei 0, in der Schleife kommt etwas dazu.
- Zählen: Eine Variable startet bei 0 und wird um 1 erhöht, wenn eine Bedingung stimmt.
- Maximum oder Minimum suchen: Der erste Wert wird gemerkt, jeder größere (kleinere) ersetzt ihn.
- Suchen: Die Schleife läuft, bis etwas gefunden ist, oft mit einer Merkvariable wie gefunden.
- Tauschen: Drei Zeilen mit einer Hilfsvariable.

Achtung

Die häufigsten Fallen: Der Index beginnt bei 0, nicht bei 1. Die Schleife i < laenge hört beim letzten gültigen Index auf (laenge minus 1) und ist richtig, i <= laenge läuft einen Schritt zu weit. Ganzzahlige Division schneidet ab: In Java ist 7 / 2 gleich 3.

Prüfe dich

  1. In einer Schleife steht zaehler <- zaehler + 1, aber nur, wenn eine Bedingung stimmt. Welches Muster ist das?
    • Zählen
    • Suchen
    • Tauschen
    • Summieren
  2. Was ist bei „Beschreiben Sie die Aufgabe dieser Methode“ die beste Antwort?
    • Jede Zeile der Methode der Reihe nach in eigenen Worten nacherzählen
    • Die Namen aller Variablen mit ihren Datentypen aufzählen
    • „Sie enthält eine Schleife und eine Verzweigung und gibt etwas zurück“
    • Ein Satz zum Ergebnis, etwa „Sie gibt die Summe aller geraden Zahlen zurück“
  3. Was ist ein Schreibtischtest?
    • Ein Test, bei dem ein Kollege den Code am Bildschirm liest und bewertet
    • Ein Programm von Hand durchspielen und die Werte in einer Tabelle mitschreiben
    • Ein automatischer Test, der nach jedem Speichern auf dem Server läuft
    • Ein Test, bei dem nur geprüft wird, ob der Compiler Fehler meldet

Schleifen: Warenkorb, Login-Versuche, Ticketlisten

Ziel dieser Lektion

Du gehst mit for durch Listen und Zahlenbereiche (range), wiederholst mit while, bis eine Bedingung erfüllt ist, steuerst mit break und continue, verfolgst Schleifen im Schreibtischtest und erkennst Endlosschleifen und Off-by-one-Fehler.

Szenario: Onlineshop

Ein kleiner Onlineshop für IT-Zubehör: Artikel mit Preis und Lagerbestand, ein Warenkorb, Rabatte und Versandkosten. Ab 50 Euro ist der Versand kostenlos.

Der Stoff

Wiederholen statt kopieren

Ein Warenkorb hat mal zwei, mal zwanzig Artikel. Statt jede Zeile zu kopieren, wiederholt eine Schleife denselben Block für jedes Element. In Python geht for direkt durch die Elemente einer Liste, ganz ohne Zähler. Wie man Schleifen von Hand nachrechnet, zeigt der Schreibtischtest: eine Tabelle mit dem Stand der Variablen nach jedem Durchlauf.

Den Warenkorb summieren

Python

preise_in_cent = [1999, 999, 4950]
Eine Liste mit drei Preisen. Mehr dazu in Modul 6.
2
summe = 0
Startwert vor der Schleife.
3
for preis in preise_in_cent:
preis nimmt nacheinander jeden Wert der Liste an.
4
    summe += preis
Kurz für summe = summe + preis.
5
    print("Zwischensumme:", summe)
6
print("Warenkorb:", summe, "Cent")
Nicht eingerückt: läuft einmal, nach der Schleife.
In der Praxis

Summen, Zähler und Durchschnitte über eine Liste sind die häufigste Schleife überhaupt: Warenkorbwert, offene Tickets, Umsatz des Tages.

Mit Index: range und enumerate

Manchmal brauchst du die Position, den Index. Er beginnt bei 0. range(n) liefert die Zahlen 0 bis n − 1, range(start, ende, schritt) zählt von start bis vor ende. Wer Index und Element braucht, nimmt enumerate: Das ist lesbarer als range(len(liste)).

Index und Nummer

Python
1
artikel = ["USB-C-Kabel", "Funkmaus", "Tastatur"]
2
for i in range(len(artikel)):
len liefert 3, range(3) die Indizes 0, 1, 2.
3
    print(i, artikel[i])
4
for nr, name in enumerate(artikel, start=1):
enumerate liefert Paare aus Nummer und Element, hier ab 1 gezählt.
5
    print(f"{nr}. {name}")
In der Praxis

Listen für Menschen beginnen bei 1 (Position 1 im Warenkorb), Listen im Code bei 0. enumerate mit start=1 übersetzt zwischen beiden Welten.

range auf einen Blick

Dass die Ende-Zahl nicht dazugehört, ist die häufigste Quelle für Off-by-one-Fehler: eine Runde zu viel oder zu wenig.

AufrufliefertMerksatz
range(5)0, 1, 2, 3, 4fünf Zahlen, ab 0
range(1, 5)1, 2, 3, 4die Ende-Zahl gehört nie dazu
range(0, 10, 3)0, 3, 6, 9dritter Wert ist die Schrittweite
range(5, 0, -1)5, 4, 3, 2, 1rückwärts mit negativem Schritt

while: wiederholen, solange es nötig ist

Bei for steht vorher fest, wie oft es läuft. while wiederholt, solange die Bedingung wahr ist, und prüft sie vor jedem Durchlauf. Darum heißt sie kopfgesteuert. Wer vergisst, in der Schleife etwas an der Bedingung zu ändern, baut eine Endlosschleife. Eine fußgesteuerte Schleife (do-while) kennt Python nicht, man schreibt while True: und verlässt sie mit break.

Begrenzte Wiederholungen schützen jedes Login vor Passwort-Raten. Nach drei Fehlversuchen sperrt die Benutzerverwaltung das Konto.

Typische Stolperfallen

Achtung

Endlosschleife: while menge > 0: ohne menge -= 1 im Block läuft ewig. Im Terminal brichst du mit Strg+C ab.

Achtung

Off-by-one: range(1, len(liste)) überspringt das erste Element, range(len(liste) + 1) greift über das Ende hinaus.

Tipp

Eine Liste nie in der for-Schleife verändern, die über sie läuft. Sammle die Änderungen in einer neuen Liste.

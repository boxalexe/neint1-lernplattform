Klassen und Objekte

Ziel dieser Lektion

Du verstehst die Idee der Objektorientierung und kannst eine einfache Klasse mit Attributen und Methoden schreiben.

Die Idee dahinter

Bauplan und Exemplar

Eine Klasse ist ein Bauplan, ein Objekt ein einzelnes Exemplar, das nach diesem Plan gebaut wurde. Aus dem Bauplan „Hund“ entstehen viele konkrete Hunde: „Bello“, „Luna“, „Rex“. Alle haben dieselben Eigenschaften (Name, Alter), aber jeder mit eigenen Werten.

Die Begriffe

Diese Wörter verwendest du in jeder objektorientierten Sprache, nur die Schreibweise unterscheidet sich.

BegriffBedeutungBeispiel
KlasseBauplanHund
Objekt / Instanzein konkretes Exemplarder Hund „Bello“
Attribut (Eigenschaft)Daten, die ein Objekt speichertname, alter
MethodeFunktion, die zum Objekt gehört (Verhalten)bellen()
KonstruktorSpezialmethode, die ein neues Objekt anlegt und startetbeim Anlegen den Namen setzen

Warum das Ganze?

Statt viele lose Variablen und Funktionen zu verwalten, bündelt ein Objekt zusammengehörige Daten und Verhalten. Ein Konto-Objekt kennt seinen Kontostand und bietet einzahlen() und abheben() an. Das ordnet größere Programme und bildet die echte Welt gut nach.

Kapselung

Ein Objekt soll seine Daten schützen: Von außen darf man den Kontostand nur über die Methoden ändern (so kann abheben() prüfen, ob genug Geld da ist), nicht direkt überschreiben. Das nennt man Kapselung. Viele Sprachen haben dafür Schlüsselwörter wie private.

Typische Stolperfallen

Achtung

Eine Klasse beschreiben und ein Objekt erzeugen sind zwei Schritte. Erst Hund bello = new Hund(…) (oder Entsprechendes) legt ein Objekt an, in dem Werte stehen.

Achtung

Innerhalb einer Methode brauchst du eine Möglichkeit, auf die eigenen Attribute zuzugreifen (this. bzw. self.). Ohne sie ist unklar, ob du die Variable des Objekts oder eine lokale meinst.

Achtung

Vergisst du self als ersten Parameter einer Methode oder self. vor einem Attribut, bekommst du Fehler wie takes 1 positional argument but 2 were given oder NameError.

Klassen und Objekte: aus Listen wird der Artikel

Ziel dieser Lektion

Du baust eine Klasse mit __init__ und Methoden, erzeugst Objekte, verstehst self, unterscheidest Klasse und Objekt, erkennst, dass Variablen auf Objekte verweisen, und gibst Objekte mit __str__ lesbar aus.

Szenario: Onlineshop

Ein kleiner Onlineshop für IT-Zubehör: Artikel mit Preis und Lagerbestand, ein Warenkorb, Rabatte und Versandkosten. Ab 50 Euro ist der Versand kostenlos.

Der Stoff

Vom Datenhaufen zum Artikel

Bisher stehen Namen, Preise und Bestände in getrennten Listen, verbunden nur über den Index. Rutscht eine Liste um eins, passt nichts mehr zusammen. Eine Klasse bündelt, was zusammengehört: Daten (Attribute) und das, was man damit tun kann (Methoden). Die Klasse ist der Bauplan, jedes Objekt (auch Instanz) ein gebauter Artikel mit eigenen Werten.

In der Praxis

Artikel, Kunden, Bestellungen, Tickets: In jedem Projekt sind die zentralen Dinge Klassen. Ihre Methoden sind die Regeln, etwa dass nicht mehr verkauft wird, als auf Lager ist.

Die Klasse im UML-Klassendiagramm

Oben der Name, in der Mitte die Attribute, unten die Methoden. self steht im Diagramm nicht, es ist bei jeder Methode selbstverständlich.

Was self bedeutet

Jede Methode bekommt als ersten Parameter das Objekt, für das sie läuft. Er heißt per Konvention self. maus.verkaufen(5) ist eigentlich Artikel.verkaufen(maus, 5): Python setzt maus für self ein. Darum weiß die Methode, wessen Bestand sie ändern soll.

Eine Variable enthält übrigens nicht das Objekt selbst, sondern eine Referenz darauf, einen Verweis. Zwei Variablen können auf dasselbe Objekt zeigen.

Typische Stolperfallen

Achtung

self vergessen ist der häufigste Anfängerfehler: def ist_lieferbar(): führt beim Aufruf zu „takes 0 positional arguments but 1 was given“, weil Python das Objekt trotzdem übergibt.

Tipp

Lege alle Attribute in __init__ an. Wer sie später irgendwo neu erfindet, macht das Objekt unberechenbar.

Tipp

Klassennamen in CamelCase (DigitalArtikel), Methoden und Attribute in snake_case (preis_in_cent).

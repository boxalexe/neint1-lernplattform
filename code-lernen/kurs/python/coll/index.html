Listen, Arrays und Texte

Ziel dieser Lektion

Du kannst viele Werte in einer Sammlung speichern, auf einzelne Werte zugreifen und alle durchlaufen.

Die Idee dahinter

Viele Werte, ein Name

Fünf Noten in fünf Variablen note1 bis note5 zu speichern, wäre mühsam. Eine Liste (auch Array oder Feld) speichert viele Werte geordnet unter einem Namen: noten = [2, 1, 3, 2, 5]. Man stellt sie sich als Reihe nummerierter Fächer vor.

Der Index beginnt bei 0

Jedes Fach hat eine Nummer, den Index. Wichtig: Gezählt wird ab 0. Das erste Element hat den Index 0, das letzte bei 5 Elementen den Index 4 (also Länge minus 1). Das ist ungewohnt, gilt aber in praktisch allen Sprachen (außer SQL und einigen Spezialfällen).

Alle Elemente durchlaufen

Listen und Schleifen sind ein perfektes Paar: Mit einer Schleife besuchst du jedes Element einmal (Summe, Durchschnitt, Maximum, Suchen). Die meisten Sprachen haben dafür eine eigene „für jedes Element“-Schleife (for … in, foreach).

Texte sind auch Sammlungen

Ein Text (String) ist eine Folge einzelner Zeichen. Auch dort gibt es Länge und Index: "Hallo" hat 5 Zeichen, das erste (H) steht bei Index 0.

In Python

Listen

Python
1
namen = ["Ada", "Alan", "Grace"]
Eine Liste in eckigen Klammern.
2
print(namen[0])
Erstes Element, Index 0: Ada
3

Negative Indizes zählen von hinten. -1 ist das letzte Element: Grace

Ersetzt das zweite Element.
5
namen.append("Tim")
append hängt hinten etwas an. Jetzt sind es 4 Elemente.
6

len() liefert die Länge: 4
7
for name in namen:
Geht alle Elemente der Reihe nach durch.
8
    print(name)
Gibt jedes Element aus.

Durchschnitt einer Liste

Die Schleife besucht jedes Element. In der Variablentabelle siehst du, wie die Liste unverändert bleibt und summe wächst.

Pseudocode
1
noten <- [2, 1, 3, 2, 5]
2
summe <- 0
3
FÜR JEDES n IN noten
4
  summe <- summe + n
5
ENDE FÜR
6
durchschnitt <- summe / LÄNGE(noten)
7
AUSGABE "Durchschnitt:", durchschnitt

Das größte Element finden

Das Standardverfahren: Merke dir das bisher größte Element und ersetze es, sobald du ein größeres siehst. Starte mit dem ersten Element.

Pseudocode
1
zahlen <- [3, 9, 2, 7]
2
hoechste <- zahlen[0]
3
FÜR JEDES z IN zahlen
4
  WENN z > hoechste DANN
5
    hoechste <- z
6
  ENDE WENN
7
ENDE FÜR
8
AUSGABE "Maximum:", hoechste

Typische Stolperfallen

Achtung

Index außerhalb: Bei 5 Elementen gibt es die Indizes 0 bis 4. Ein Zugriff auf Index 5 ist ein Fehler (oder in C: Zugriff auf fremden Speicher!).

Achtung

Liste leer? Das Maximum einer leeren Liste gibt es nicht. Prüfe vorher mit der Länge, ob überhaupt etwas drinsteckt.

Achtung

Beim Kopieren einer Liste (b = a) bekommst du in vielen Sprachen nicht eine zweite Liste, sondern nur einen zweiten Namen für dieselbe. Änderungen über b ändern dann auch a.

Achtung

Mit b = a kopierst du eine Liste nicht: Beide Namen zeigen auf dieselbe Liste. Eine echte Kopie bekommst du mit b = a.copy() oder b = list(a).

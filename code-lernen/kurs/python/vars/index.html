Variablen, Datentypen und Umwandlung: Preise, Mengen, Eingaben

Ziel dieser Lektion

Du legst Variablen an, kennst int, float, str, bool und None, rechnest mit + - * / // % und **, wandelst Eingaben mit int() und float() um, setzt Werte mit f-Strings in Text ein und weißt, warum Geldbeträge in Cent gerechnet werden.

Szenario: Onlineshop

Ein kleiner Onlineshop für IT-Zubehör: Artikel mit Preis und Lagerbestand, ein Warenkorb, Rabatte und Versandkosten. Ab 50 Euro ist der Versand kostenlos.

Der Stoff

Werte mit Namen

Der Shop muss sich Dinge merken: welcher Artikel, welcher Preis, wie viele Stück. Eine Variable ist ein Name für einen Wert. menge = 2 legt die Variable menge an und speichert 2. Das = heißt „bekommt den Wert“, nicht „ist gleich“.

Einen Datentyp schreibst du in Python nicht hin. Python ist dynamisch typisiert: Der Typ gehört zum Wert, nicht zum Namen. 2 ist eine ganze Zahl, "2" ein Text. Mit type() fragst du nach.

Ein Artikel in Variablen

Python
1
artikel = "Funkmaus"
Text, Typ str.
2
preis_in_cent = 1999
Ganze Zahl, Typ int. Geldbeträge in Cent: so gibt es keine Rundungsfehler.
3
menge = 2
4
lieferbar = True
Wahrheitswert, Typ bool. True und False schreibt man groß.
5
gewicht_kg = 0.12
Kommazahl, Typ float. Mit Punkt statt Komma.
6
summe_in_cent = preis_in_cent * menge
Rechts wird zuerst gerechnet, das Ergebnis wandert in die neue Variable.
7
print(artikel, summe_in_cent)
8
print(type(preis_in_cent), type(gewicht_kg), type(artikel), type(lieferbar))
type verrät den Datentyp eines Werts.
In der Praxis

Preise in Cent als ganze Zahl sind in Shops, Banken und Kassensystemen Standard. Ein float wie 19.99 lässt sich im Rechner nicht exakt speichern, und bei tausend Buchungen läuft das sichtbar auseinander.

Die wichtigsten Datentypen

Ein Literal ist ein Wert, der direkt im Code steht. Anders als Java kennt Python keine Größenbeschränkung für int: Auch 2 ** 100 rechnet es exakt.

TypBedeutungBeispiel-Literal
intganze Zahl, beliebig groß1999, -5, 0
floatKommazahl (mit Punkt)0.12, 19.99
strText"Funkmaus", 'A'
boolWahrheitswertTrue, False
None„kein Wert“None

Rechnen

Neben + - * gibt es drei Divisionsarten. / liefert immer eine Kommazahl, auch bei 4 / 2. // teilt ganzzahlig und schneidet den Rest ab. % liefert genau diesen Rest. Zusammen zerlegen sie einen Cent-Betrag in Euro und Cent. ** ist die Potenz.

Euro, Cent und Rundungsfehler

Python
1
summe_in_cent = 3998
2
euro = summe_in_cent // 100
Ganzzahlige Division: 39.
3
cent = summe_in_cent % 100
Rest der Division: 98.
4
print(euro, "Euro und", cent, "Cent")
5
print(7 / 2, 7 // 2, 7 % 2, 2 ** 10)
3.5, 3, 1 und 1024.
6
print(0.1 + 0.2)
Nicht 0.3: Kommazahlen sind im Rechner binär gespeichert und oft nur fast genau.
In der Praxis

Rechnungen zeigen Beträge als 39,98 Euro, gerechnet wird intern in Cent. // und % zerlegen den Betrag für die Anzeige, ohne dass je eine Kommazahl entsteht.

Eingaben umwandeln

input() liest eine Zeile von der Tastatur und liefert immer Text, auch wenn jemand 2 tippt. Rechnen geht erst nach dem Parsen: int("2") macht daraus die Zahl 2, float("19.99") eine Kommazahl. Umgekehrt macht str(2) aus der Zahl einen Text. Ist der Text keine Zahl, etwa int("zwei"), bricht das Programm mit einem ValueError ab. Wie man das abfängt, kommt in Modul 10.

Eine Menge einlesen

Python
1
eingabe = input("Menge: ")
Liefert Text, etwa "3".
2
menge = int(eingabe)
Parsen: aus "3" wird 3.
3
print("Gesamt:", menge * 1999, "Cent")
Erst jetzt ist es eine Rechnung. Mit dem Text "3" käme "333…" heraus.
In der Praxis

Jedes Formularfeld im Shop liefert Text, auch das Mengenfeld. Bevor gerechnet wird, muss das Programm parsen, und bei Unsinn wie zwei statt 2 sauber reagieren.

Werte in Text einsetzen

Ein f-String hat ein f vor dem Anführungszeichen. Was in geschweiften Klammern steht, rechnet Python aus und setzt es ein. Hinter einem Doppelpunkt folgt das Format: :.2f heißt zwei Nachkommastellen. Die Alternative ist Verkettung mit +, die aber nur Text mit Text verbindet.

Eine Konstante schreibt man in Python groß: VERSAND_IN_CENT = 495. Python verhindert eine Änderung nicht, der Name sagt allen: Dieser Wert bleibt fest.

f-Strings und Verkettung

Python
1
artikel = "Funkmaus"
2
menge = 2
3
summe_in_cent = 3998
4
print(f"{menge} x {artikel}: {summe_in_cent / 100:.2f} Euro")
Drei eingesetzte Werte, der letzte mit zwei Nachkommastellen.
5
print("Artikel: " + artikel + ", Menge: " + str(menge))
Verkettung: Die Zahl muss erst mit str zu Text werden.
6
VERSAND_IN_CENT = 495
Konstante: Großbuchstaben als Zeichen „nicht ändern“.
7
print(f"Mit Versand: {(summe_in_cent + VERSAND_IN_CENT) / 100:.2f} Euro")
In der Praxis

Bestellmails, Logzeilen und Fehlermeldungen bestehen aus festem Text mit eingesetzten Werten. f-Strings sind dafür die übliche Schreibweise in Python-Projekten.

Typische Stolperfallen

Achtung

"5" + 3 ist ein TypeError: Text und Zahl lassen sich nicht addieren. Entweder int("5") + 3 ergibt 8 oder "5" + str(3) ergibt "53".

Tipp

Variablennamen schreibt man in Python klein mit Unterstrich: preis_in_cent, anzahl_kunden (snake_case, Regel aus dem Styleguide PEP 8). Mit Einheit im Namen weiß jeder, ob Euro oder Cent gemeint ist.

Achtung

= weist zu, == vergleicht. menge = 3 speichert, menge == 3 fragt nur.

Prüfe dich

  1. Was liefert input() immer zurück?
    • Text (str)
    • Eine ganze Zahl
    • True oder False
    • Eine Kommazahl
  2. Was ergibt 17 // 5 und was 17 % 5?
    • 3.4 und 2
    • 2 und 3
    • 3 und 2
    • 3 und 0.4
  3. Warum speichert der Shop Preise in Cent als int?
    • int braucht weniger Platz als ein Text
    • Kommazahlen sind binär oft nur fast genau
    • Cent-Beträge sind gesetzlich vorgeschrieben
    • Python kann mit float nicht multiplizieren
  4. Was bedeutet „dynamisch typisiert“?
    • Variablen dürfen ihren Wert nicht ändern
    • Jede Variable muss vorher mit Typ deklariert werden
    • Der Typ gehört zum Wert und wird beim Ausführen geprüft
    • Python wandelt Text und Zahl immer selbst um

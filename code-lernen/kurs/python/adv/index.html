Vertiefung: Comprehensions, Lambdas, Dateien und Module

Ziel dieser Lektion

Du baust Listen mit Comprehensions, sortierst mit Lambdas als Schlüssel, liest und schreibst Dateien sicher mit with, nutzt Module aus der Standardbibliothek und weißt, wofür if __name__ == "__main__" da ist.

Szenario: IT-Ticketsystem

Ein Service-Desk: Störungen kommen als Tickets mit Priorität (1 = kritisch bis 4 = niedrig) und Status (offen, in Arbeit, erledigt) und werden Technikern zugewiesen.

Der Stoff

Das Werkzeug der letzten Meter

Der Service-Desk verwaltet Tickets mit Titel und Priorität (1 = kritisch bis 4 = niedrig). Alles, was du dafür brauchst, kennst du schon. Typischer Python-Code nutzt dafür ein paar Abkürzungen: List Comprehensions bauen eine Liste in einer Zeile, Lambdas sind kleine Funktionen ohne Namen, with öffnet Dateien sicher, und jedes Modul der Standardbibliothek bringt fertige Werkzeuge mit.

Hinter jeder Comprehension steckt eine Schleife, hinter jedem Lambda eine Funktion. Genau so liest du sie auch.

In der Praxis

Filtern und Umrechnen von Listen ist Alltag: alle offenen Tickets, alle Preise mit Steuer, alle ausverkauften Artikel. In Python-Projekten schreibt man das fast immer als Comprehension.

In der Praxis

Sortieren nach einer Spalte, das kleinste Element nach einem Kriterium: Überall, wo eine Funktion „irgendeine Regel“ von dir braucht, übergibst du ein kurzes Lambda.

In der Praxis

Jede Python-Datei ist selbst ein Modul. Mit if __name__ == "__main__" lässt sie sich direkt starten und trotzdem von anderen Dateien importieren, etwa von Tests, ohne dass dabei gleich das ganze Programm losläuft.

Schleife und Comprehension im Vergleich

Wird die Comprehension länger als eine Zeile oder braucht sie mehrere if, ist die Schleife wieder die lesbarere Wahl.

Mit SchleifeAls Comprehension
ergebnis = [] for p in preise: ergebnis.append(p * 2)[p * 2 for p in preise]
ergebnis = [] for p in preise: if p < 4000: ergebnis.append(p)[p for p in preise if p < 4000]
d = {} for name, n in lager.items(): d[name] = n > 0{name: n > 0 for name, n in lager.items()}

Typische Stolperfallen

Tipp

In der IHK-Prüfung schreibst du Pseudocode und Schleifen, keine Comprehensions. Wer beides kann, liest Prüfungsaufgaben und Projektcode gleich sicher.

Achtung

liste.sort() sortiert die Liste selbst und liefert None. sorted(liste) liefert eine neue, sortierte Liste. Wer x = liste.sort() schreibt, hat danach None in x.

Tipp

Lambdas nur für kurze Regeln. Braucht die Regel mehr als einen Ausdruck, schreib eine Funktion mit def und sprechendem Namen.

  1. Was ergibt [n * 2 for n in [1, 2, 3] if n != 2]?
    • [4]
    • [1, 3]
    • [2, 4, 6]
    • [2, 6]
  2. Was macht key=lambda t: t[1] in sorted?
    • Sortiert nur die ersten zwei Elemente
    • Löscht das zweite Element jedes Tupels
    • Sortiert nach dem zweiten Wert jedes Elements
    • Sortiert rückwärts
  3. Warum öffnet man Dateien mit with open(…)?
    • with macht das Lesen doppelt so schnell
    • Die Datei wird garantiert wieder geschlossen
    • Nur so lassen sich Umlaute lesen
    • Ohne with kann Python nicht schreiben
  4. Wann ist __name__ == "__main__" wahr?
    • Wenn die Datei importiert wird
    • Nur in der Datei main.py
    • Immer, in jeder Datei
    • Wenn die Datei direkt gestartet wird

Funktionen: Versand, Rabatt und Prüfungen als Bausteine

Ziel dieser Lektion

Du schreibst Funktionen mit def, übergibst Parameter, lieferst Ergebnisse mit return, nutzt Standardwerte und Schlüsselwortargumente, unterscheidest lokale und globale Variablen und verfolgst Aufrufe im Ablauf.

Szenario: Onlineshop

Ein kleiner Onlineshop für IT-Zubehör: Artikel mit Preis und Lagerbestand, ein Warenkorb, Rabatte und Versandkosten. Ab 50 Euro ist der Versand kostenlos.

Der Stoff

Einmal schreiben, überall nutzen

Die Versandregel steht bisher mitten im Code. Braucht der Warenkorb, die Rechnung und die Bestellübersicht sie, stünde sie dreimal da, und bei einer Änderung vergisst man garantiert eine Stelle. Eine Funktion gibt einem Stück Code einen Namen. Sie bekommt Werte über Parameter und liefert ihr Ergebnis mit return zurück, den Rückgabewert.

In der Praxis

Geschäftsregeln wie Versand, Rabatt oder Mehrwertsteuer stehen in echten Shops in genau einer Funktion. Ändert sich die Regel, ändert sich eine Stelle, und ein Test prüft sie.

Standardwerte und Schlüsselwortargumente

Ein Parameter kann einen Standardwert haben: prozent=10. Wer nichts angibt, bekommt ihn. Beim Aufruf darfst du Werte auch mit Namen übergeben, ab_in_cent=5000. Das liest sich wie ein Satz und ist unabhängig von der Reihenfolge.

In der Praxis

Aktionen im Shop („15 % auf alles ab 50 Euro“) ändern nur Argumente, nicht die Funktion. Benannte Argumente machen solche Aufrufe auch Monate später noch verständlich.

return oder print?

print zeigt etwas an, return gibt etwas zurück. Eine Funktion ohne return liefert None, „kein Wert“. Wer mit dem Ergebnis rechnen will, braucht return. Faustregel: Funktionen rechnen und geben zurück, ausgegeben wird an einer Stelle außerhalb.

In der Praxis

Eine Funktion, die nur druckt, lässt sich nicht testen und nicht weiterverwenden. In Projekten liefern Funktionen Werte; ob die in einer Konsole, einer Webseite oder einer Mail landen, entscheidet der Aufrufer.

In der Praxis

Lokale Variablen sind ein Schutz: Was in einer Funktion passiert, kann nichts außerhalb versehentlich überschreiben. Globale Werte sind darum in Projekten fast immer Konstanten.

Die Begriffe rund um Funktionen

In der IHK-Prüfung heißen Funktionen in Klassen Methoden. In Python heißen sie außerhalb von Klassen Funktionen, das Prinzip ist dasselbe.

Typische Stolperfallen

Achtung

Nie eine Liste als Standardwert: def f(liste=[]) teilt sich dieselbe Liste über alle Aufrufe. Richtig ist def f(liste=None) und im Rumpf if liste is None: liste = [].

Tipp

Eine Funktion, eine Aufgabe. Lässt sich ihr Name nicht ohne „und“ formulieren, teile sie auf.

Tipp

Eine Zeile Text in dreifachen Anführungszeichen direkt unter def ist ein Docstring: Er erklärt, was die Funktion tut, und erscheint bei help(funktion).

Vertiefung: Zeiger und dynamischer Speicher

Ziel dieser Lektion

Du verstehst, was ein Zeiger ist, kannst Variablen über Adressen ändern und weißt, wofür malloc und free da sind.

Der Stoff

Was ist ein Zeiger?

Jede Variable liegt an einer Adresse im Speicher. Ein Zeiger ist eine Variable, die so eine Adresse speichert. Mit &x holst du die Adresse von x, mit *p greifst du auf das zu, worauf p zeigt.

Adresse und Zugriff

C
1
int x = 5;
Eine normale Variable.
2
int *p = &x;
p ist ein Zeiger auf int und speichert die Adresse von x.
3
*p = 9;
Schreibt über den Zeiger: x ist jetzt 9.
4
printf("%d\n", x);
Ausgabe: 9

Variablen in Funktionen ändern

C
1
void erhoehe(int *zahl) {
Die Funktion bekommt die Adresse.
2
    *zahl = *zahl + 1;
Ändert den Wert am Original.
3
}
Ende.
4
 
5
int a = 5;
Die Variable.
6
erhoehe(&a);
Wir übergeben die Adresse.
7
printf("%d\n", a);
Jetzt 6: So ändert man Variablen in Funktionen.

malloc und free

Speicher, dessen Größe du erst beim Laufen kennst, forderst du selbst an: malloc gibt ihn dir, free gibst du ihn zurück. Wer nie free aufruft, hat ein Speicherleck.

Speicher anfordern und freigeben

C
1
#include <stdlib.h>
Für malloc und free.
2
int n = 3;
Anzahl der gewünschten Zahlen.
3
int *feld = malloc(n * sizeof(int));
Fordert Speicher für 3 int an und liefert die Adresse.
4
if (feld == NULL) {
malloc kann scheitern und liefert dann NULL.
5
    return 1;
Dann abbrechen.
6
}
Ende der Prüfung.
7
for (int i = 0; i < n; i++) {
Alle Plätze füllen.
8
    feld[i] = i * 10;
Zeiger lassen sich wie Arrays benutzen.
9
}
Ende.
10
printf("%d\n", feld[2]);
Ausgabe: 20
11
free(feld);
Zurückgeben! Danach darf man feld nicht mehr benutzen.

Typische Stolperfallen

Achtung

Typische Zeigerfehler: Zugriff nach free, doppeltes free, Zugriff auf NULL, nicht initialisierte Zeiger. Sie führen zu Abstürzen oder zu Sicherheitslücken. Werkzeug dagegen: Valgrind oder -fsanitize=address beim Übersetzen.

Prüfe dich

  1. Was liefert &x?
    • Den Wert, auf den x zeigt
    • Eine Kopie des Werts von x
    • Die Adresse der Variable x
    • Den Wert von x als Wahrheitswert
  2. Was passiert, wenn man malloc nutzt und nie free aufruft?
    • Der Compiler gibt den Speicher selbst frei
    • Ein Speicherleck: Der Speicher bleibt belegt
    • Das Programm bricht sofort mit Fehler ab
    • Der Speicher wird beim nächsten malloc wiederverwendet

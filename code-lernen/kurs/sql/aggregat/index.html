Zählen, Summieren und Gruppieren

Ziel dieser Lektion

Du kannst mit COUNT, SUM, AVG, MIN und MAX auswerten und Ergebnisse mit GROUP BY gruppieren.

Der Stoff

Aus vielen Zeilen eine Zahl

Aggregatfunktionen fassen viele Zeilen zu einem Wert zusammen:
- COUNT(*) Anzahl der Zeilen
- SUM(spalte) Summe
- AVG(spalte) Durchschnitt
- MIN(spalte), MAX(spalte) kleinster und größter Wert

Zählen

SQL
1
SELECT COUNT(*) AS anzahl
Zählt alle Zeilen im Ergebnis.
2
FROM kunde;
Ergebnis: 8 Kunden.

Kleinster, größter, durchschnittlicher Wert

SQL
1
SELECT MIN(preis), MAX(preis), ROUND(AVG(preis), 2)
Kleinster, größter und auf 2 Stellen gerundeter durchschnittlicher Preis.
2
FROM produkt;
Eine einzige Ergebniszeile.

Gruppieren mit GROUP BY

Oft willst du die Auswertung je Gruppe: „Wie viele Produkte gibt es je Kategorie?“ GROUP BY kategorie bildet für jede Kategorie eine Gruppe, und die Aggregatfunktion rechnet innerhalb jeder Gruppe.

Je Kategorie zählen

SQL
1
SELECT kategorie, COUNT(*) AS anzahl
Die Spalte, nach der gruppiert wird, plus eine Zählung.
2
FROM produkt
Aus produkt.
3
GROUP BY kategorie;
Eine Ergebniszeile je Kategorie: Computer, Zubehör, Audio mit ihrer Anzahl.

Gruppen filtern mit HAVING

SQL
1
SELECT kategorie, COUNT(*) AS anzahl
Pro Kategorie die Anzahl.
2
FROM produkt
Aus produkt.
3
GROUP BY kategorie
Gruppen bilden.
4
HAVING COUNT(*) > 1;
HAVING filtert Gruppen nach dem Gruppieren. Nur Kategorien mit mehr als einem Produkt bleiben.

Typische Stolperfallen

Achtung

In einer Abfrage mit GROUP BY darfst du in SELECT nur die Gruppierungsspalten und Aggregate angeben. SELECT name, COUNT(*) … GROUP BY kategorie ergibt keinen Sinn: Welcher von vielen Namen soll gemeint sein?

Prüfe dich

  1. Du willst nur Kategorien mit mehr als einem Produkt. Was nimmst du?
    • LIMIT 1
    • HAVING COUNT(*) > 1
    • ORDER BY COUNT(*) > 1
    • WHERE COUNT(*) > 1
  2. Was liefert SELECT AVG(preis) FROM produkt;?
    • Eine Zeile mit dem höchsten Preis
    • Eine Zeile mit dem Durchschnittspreis
    • Eine Zeile je Produkt mit seinem Preis
    • Eine Zeile mit der Summe aller Preise

Übungen

  1. Wie viele Produkte gibt es? (Eine Zahl.)

  2. Zeige, wie viele Kunden je Stadt es gibt (Stadt und Anzahl).

  3. Zeige den durchschnittlichen Preis je Kategorie (Kategorie und Durchschnitt).

  4. Zeige die gesamte bestellte Menge (alle Bestellungen zusammen). Eine Zahl.

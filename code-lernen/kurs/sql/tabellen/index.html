Tabellen entwerfen mit CREATE TABLE

Ziel dieser Lektion

Du kannst eigene Tabellen mit Datentypen und Schlüsseln anlegen und kennst die Grundidee guter Datenmodelle.

Der Stoff

Eine Tabelle anlegen

SQL
1
CREATE TABLE lieferant (
Legt eine neue Tabelle namens lieferant an. In Klammern stehen die Spalten.
2
  id INTEGER PRIMARY KEY,
Spalte id mit ganzen Zahlen. PRIMARY KEY macht sie zum eindeutigen Schlüssel.
3
  name TEXT NOT NULL,
Spalte name mit Text. NOT NULL: Es muss immer ein Wert angegeben werden.
4
  land TEXT DEFAULT 'Deutschland'
Ohne Angabe wird automatisch Deutschland eingetragen.
5
);
Ende der Tabellendefinition.

Die wichtigsten Datentypen

Die genauen Typnamen unterscheiden sich je nach Datenbanksystem (MySQL, PostgreSQL, SQL Server), das Prinzip bleibt gleich.

DatentypSpeichertBeispiel
INTEGERganze Zahlen42
REALKommazahlen19.99
TEXTTexte'Berlin'
DATE / TextDatumsangaben (in SQLite als Text JJJJ-MM-TT)'2024-05-30'

Fremdschlüssel festlegen

SQL
1
CREATE TABLE bewertung (
Eine Tabelle für Produktbewertungen.
2
  id INTEGER PRIMARY KEY,
Eigener Schlüssel.
3
  produkt_id INTEGER NOT NULL,
Zu welchem Produkt gehört die Bewertung?
4
  sterne INTEGER,
1 bis 5 Sterne.
5
  FOREIGN KEY (produkt_id) REFERENCES produkt(id)
Der Fremdschlüssel: produkt_id muss ein vorhandenes Produkt sein. Die Datenbank sichert die Verknüpfung ab.
6
);
Ende.

Gute Tabellen: ein Gedanke, ein Ort

  • Jede Tabelle beschreibt eine Sache (Kunden, Produkte, Bestellungen).
  • Jede Information steht nur einmal. Der Kundenname gehört in kunde, nicht in jede Bestellung.
  • Jede Zeile hat einen Primärschlüssel.
  • Verknüpfungen laufen über Fremdschlüssel.

Das Vorgehen, Daten so aufzuteilen, dass nichts doppelt steht, heißt Normalisierung.

Typische Stolperfallen

Achtung

Wenn du in einer Tabelle Spalten wie produkt1, produkt2, produkt3 hast, fehlt dir eine zweite Tabelle. Lege lieber eine Tabelle an, in der jede Zeile ein Produkt ist.

Prüfe dich

  1. Was bewirkt NOT NULL bei einer Spalte?
    • Die Spalte wird nicht angezeigt
    • Es muss immer ein Wert eingetragen werden
    • Die Werte der Spalte müssen in jeder Zeile verschieden sein
    • Die Spalte darf nur Zahlen enthalten

Übungen

  1. Lege eine Tabelle lieferant mit den Spalten id (ganze Zahl, Primärschlüssel) und name (Text) an.

Entscheidungen: if und else

Ziel dieser Lektion

Du kannst ein Programm je nach Situation unterschiedliche Wege gehen lassen.

Die Idee dahinter

Wenn … dann … sonst …

Im Alltag entscheidest du ständig: Wenn es regnet, dann nimm den Schirm, sonst nicht. Ein Programm macht dasselbe mit einer Bedingung: einer Frage, die nur mit WAHR oder FALSCH beantwortet wird. Ist sie WAHR, läuft ein Block von Anweisungen, sonst läuft der andere (oder keiner).

Mehrere Möglichkeiten

Mit „sonst wenn“ hängst du weitere Fragen an. Das Programm prüft von oben nach unten und nimmt den ersten Zweig, dessen Bedingung stimmt. Alle weiteren Zweige werden dann übersprungen. Darum ist die Reihenfolge wichtig, und der letzte „sonst“-Zweig fängt alles auf, was übrig bleibt.

Gut zu wissen

Jeder Zweig ist ein Block: eine Gruppe von Anweisungen, die zusammengehören. Wie man den Block markiert (Einrückung, geschweifte Klammern, END IF), unterscheidet sich je nach Sprache. Die Idee ist immer dieselbe.

Ein Notenschlüssel

Beobachte: Für 72 Punkte werden die ersten beiden Bedingungen FALSCH, die dritte WAHR. Danach springt das Programm direkt hinter ENDE WENN. Ändere probehalber punkte in der Spielwiese.

Pseudocode
1
punkte <- 72
2
WENN punkte >= 90 DANN
3
  note <- "sehr gut"
4
SONST WENN punkte >= 75 DANN
5
  note <- "gut"
6
SONST WENN punkte >= 50 DANN
7
  note <- "bestanden"
8
SONST
9
  note <- "durchgefallen"
10
ENDE WENN
11
AUSGABE "Ergebnis:", note

Typische Stolperfallen

Achtung

Reihenfolge der Prüfungen. Würdest du punkte >= 50 zuerst prüfen, bekäme jeder ab 50 Punkten „bestanden“, auch 95 Punkte, weil der erste passende Zweig gewinnt. Prüfe immer vom Engsten zum Weitesten.

Achtung

Randwerte: Gehört die 50 noch zu „bestanden“ oder nicht? Der Unterschied zwischen > und >= entscheidet. Teste deine Bedingungen bewusst mit den Grenzwerten.

Achtung

Vergleichen heißt in den meisten Sprachen == (zwei Gleichheitszeichen). Ein einzelnes = weist etwas zu.

Achtung

if (x = 5) ist in Java ein Fehler beim Übersetzen, weil x = 5 kein Wahrheitswert ist. Das schützt dich vor einem Fehler, der in C passiert. Vergleichen heißt ==.

Prüfe dich

  1. In einer Kette aus „wenn / sonst wenn / sonst“ ist die erste Bedingung WAHR. Was passiert mit den restlichen Zweigen?
    • Das Programm bricht ab
    • Sie werden auch geprüft und ausgeführt, wenn sie stimmen
    • Sie werden übersprungen
    • Sie werden in zufälliger Reihenfolge ausgeführt
  2. alter ist 18. Welche Bedingung ist WAHR?
    • alter != 18
    • alter < 18
    • alter > 18
    • alter >= 18
  3. Was passiert in einem switch ohne break?
    • Der switch endet nach dem Fall trotzdem
    • Der Fall wird übersprungen
    • Der Compiler meldet einen Fehler und übersetzt nicht
    • Das Programm läuft in den nächsten Fall weiter

Verzweigungen: Versandkosten, Altersfreigabe, Login-Sperre

Ziel dieser Lektion

Du liest und schreibst Geschäftsregeln mit if, else if, else und switch, setzt Bedingungen mit &&, || und ! richtig zusammen und prüfst Grenzwerte bewusst.

Szenario: Onlineshop

Ein kleiner Onlineshop für IT-Zubehör: Artikel mit Preis und Lagerbestand, ein Warenkorb, Rabatte und Versandkosten. Ab 50 Euro ist der Versand kostenlos.

Der Stoff

Geschäftsregeln sind Verzweigungen

Mit den Werten aus Modul 1 trifft der Shop jetzt Entscheidungen. Versandkostenfrei ab 50 Euro, Rabatt ab einer Bestellmenge, Konto gesperrt nach drei Fehlversuchen: Fast jede Geschäftsregel ist eine Verzweigung. Eine Bedingung wird geprüft, je nach Ergebnis läuft der eine oder der andere Zweig. Die Bedingung ist immer ein Wahrheitswert: true oder false.

Vergleichen und Verknüpfen

Welche Verzweigung wann?

FormWannBeispiel
if / elsezwei Möglichkeitenversandfrei oder nicht
else if-KetteBereiche, von oben nach unten geprüftAltersstufen, Rabattstaffel
switchein Wert gegen feste FälleBestellstatus, Priorität
?:kurzer Wert für eine Anzeige„Auf Lager“ oder „Ausverkauft“

Typische Stolperfallen

Achtung

Grenzwerte prüfen: „ab 50 Euro“ heißt >= 5000, nicht > 5000. Teste jede Bedingung mit dem Wert genau auf der Grenze, einen darunter und einen darüber.

Achtung

Reihenfolge in else-if-Ketten: Der erste wahre Zweig gewinnt. Prüfe den engsten Fall zuerst, sonst wird er nie erreicht.

Achtung

Texte in Bedingungen immer mit equals vergleichen: if (rolle.equals("ADMIN")). == vergleicht Objekte, nicht den Inhalt.

Tipp

&& bindet stärker als ||. Im Zweifel Klammern setzen: (a || b) && c sagt, was gemeint ist.

Prüfe dich

  1. In einer else-if-Kette ist die erste Bedingung wahr. Was passiert mit den übrigen Zweigen?
    • Der letzte wahre Zweig gewinnt
    • Sie werden übersprungen
    • Es gibt einen Compilerfehler
    • Sie werden auch geprüft
  2. „Versandkostenfrei ab 50 Euro“: Welche Bedingung ist richtig (Cent)?
    • warenwert >= 5000
    • warenwert == 5000
    • warenwert > 5000
    • warenwert => 5000
  3. Was passiert in einem klassischen switch ohne break?
    • Java springt zum default-Fall
    • Java beendet den switch automatisch
    • Java läuft in den nächsten Fall weiter
    • Der Compiler meldet einen Fehler
  4. Was liefert lager > 0 ? "Auf Lager" : "Ausverkauft" bei lager = 0?
    • false
    • "Auf Lager"
    • Einen Fehler
    • "Ausverkauft"

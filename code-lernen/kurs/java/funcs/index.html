Methoden: Versand, Rabatt und Prüfungen als Bausteine

Ziel dieser Lektion

Du schreibst und liest Methoden mit Parametern und Rückgabewert, trennst Berechnung (return) von Ausgabe (println), verfolgst Aufrufe im Ablauf und weißt, warum eine Methode eine übergebene Zahl nicht von außen verändern kann.

Szenario: Onlineshop

Ein kleiner Onlineshop für IT-Zubehör: Artikel mit Preis und Lagerbestand, ein Warenkorb, Rabatte und Versandkosten. Ab 50 Euro ist der Versand kostenlos.

Der Stoff

Vom Code-Block zum Baustein

In Modul 2 stand die Versandregel mitten im Programm, in Modul 3 lief sie in einer Schleife. Wird dieselbe Regel im Warenkorb, an der Kasse und in der Bestellbestätigung gebraucht, stünde sie dreimal da, und eine Änderung der Grenze müsste dreimal passieren. Eine Methode fasst sie einmal zusammen, gibt ihr einen Namen und lässt sich beliebig oft aufrufen.

Im Ablauf siehst du, wie Java beim Aufruf in die Methode springt, dort mit eigenen Variablen rechnet und mit dem Ergebnis zurückkehrt.

In der Praxis

Genau so steht die Versandregel in einem echten Shop: einmal als Methode, aufgerufen vom Warenkorb, von der Kasse und vom Rechnungsdruck. Ändert sich die Grenze, ändert man eine Zeile.

In der Praxis

Die Rabattberechnung braucht der Warenkorb, die Rechnung und die Schnittstelle zum Buchhaltungssystem. Gäbe die Methode nur aus, statt zurückzugeben, könnte keiner davon mit dem Ergebnis weiterrechnen.

In der Praxis

Ein häufiger Bug in Lagerverwaltungen: Die Methode „aktualisiert“ den Bestand, aber nur ihre eigene Kopie. Richtig ist, den neuen Wert mit return zurückzugeben: lager = erhoeheBestand(lager).

Typische Stolperfallen

Achtung

Hat eine Methode einen Rückgabetyp, muss jeder Weg durch die Methode mit return enden. Fehlt eines, meldet der Compiler „missing return statement“.

Achtung

Ein Rückgabewert, der nicht gespeichert wird, ist verloren: mitRabatt(preis, 10); allein ändert nichts.

Tipp

Mehrere Methoden dürfen denselben Namen haben, wenn ihre Parameter sich unterscheiden (Überladen): versandInCent(long wert) und versandInCent(long wert, boolean premium).

Prüfe dich

  1. Was bedeutet void als Rückgabetyp?
    • Die Methode hat keine Parameter
    • Die Methode gibt keinen Wert zurück
    • Die Methode darf nichts ausgeben
    • Die Methode ist noch leer
  2. Warum gibt mitRabatt den Preis zurück, statt ihn auszugeben?
    • Damit der Preis nicht verloren geht
    • Weil return schneller ausgibt
    • Weil println in Methoden verboten ist
    • Damit der Aufrufer weiterrechnen kann
  3. lager ist 5. Nach erhoeheBestand(lager); mit bestand = bestand + 10; in der Methode ist lager …
    • nicht mehr gültig
    • weiterhin 5
    • jetzt 10
    • jetzt 15
  4. Was passiert direkt nach return 0; in einer Methode?
    • Die Methode endet sofort
    • Das Programm endet
    • Die nächste Zeile läuft noch
    • Die Methode startet neu

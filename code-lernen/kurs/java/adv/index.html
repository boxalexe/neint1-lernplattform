Vertiefung: Schnittstellen, Generics und Lambdas

Ziel dieser Lektion

Du kennst Schnittstellen in Java, verstehst, was <T> bedeutet, und kannst einfache Lambda-Ausdrücke lesen.

Der Stoff

Schnittstellen (interface)

Eine Schnittstelle legt fest, was eine Klasse können muss. Mehrere Klassen können sie umsetzen (implements). Der Aufrufer kennt nur die Schnittstelle.

Eine Schnittstelle umsetzen

Eine Schnittstelle: nur Methoden ohne Inhalt.
2

Wer Zahlungsart umsetzt, muss diese Methode anbieten.

Generics: <T>

In ArrayList<String> steht in spitzen Klammern, was die Liste enthält. Das ist Generics: Dieselbe Klasse funktioniert für viele Typen, und der Compiler verhindert, dass du eine Zahl in eine Liste mit Texten steckst.

Lambdas und Streams

Ein Lambda ist eine kurze namenlose Funktion: x -> x * 2 heißt „nimm x, gib x * 2 zurück“. Zusammen mit Streams wertest du Listen kompakt aus.

Streams und Lambdas (Java 16 oder neuer)

Java
1
import java.util.List;
Die Klasse List.
2
List<Integer> zahlen = List.of(1, 2, 3, 4, 5);
Eine unveränderliche Liste mit fünf Zahlen.
3
List<Integer> gerade = zahlen.stream()
stream() startet eine „Fließband“-Verarbeitung der Elemente.
4
    .filter(x -> x % 2 == 0)
filter behält nur die Elemente, für die das Lambda true liefert: die geraden.
5
    .toList();
Sammelt das Ergebnis wieder in einer Liste (ab Java 16).
6
System.out.println(gerade);
Gibt aus: [2, 4]

Prüfe dich

  1. Was bedeutet ArrayList<String>?
    • Ein Array aus Zeichen
    • Eine Liste, die nur Texte enthält
    • Eine Liste von Listen
    • Eine Liste mit der Länge String
  2. Wofür steht x -> x * 2?
    • Eine Zuweisung: x wird zu x * 2
    • Ein Lambda: nimm x und liefere x * 2
    • Ein Vergleich: ist x größer als x * 2
    • Ein Zeiger, der auf x mal 2 zeigt

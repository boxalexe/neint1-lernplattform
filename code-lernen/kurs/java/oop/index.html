Klassen und Objekte: aus Arrays wird der Artikel

Ziel dieser Lektion

Du schreibst eine Klasse mit Attributen, Konstruktor und Methoden, erzeugst daraus Objekte mit new, verwaltest Objekte in einer ArrayList und unterscheidest Wert- und Referenztypen sicher.

Szenario: Onlineshop

Ein kleiner Onlineshop für IT-Zubehör: Artikel mit Preis und Lagerbestand, ein Warenkorb, Rabatte und Versandkosten. Ab 50 Euro ist der Versand kostenlos.

Der Stoff

Was zusammengehört, bleibt zusammen

Am Ende von Modul 5 standen Namen und Preise in zwei getrennten Arrays, verbunden nur über dieselbe Position. Eine Klasse löst das: Sie ist der Bauplan für einen Artikel und legt fest, welche Attribute (Name, Preis, Lager) und welche Methoden jeder Artikel hat. Mit new entsteht daraus ein Objekt, auch Instanz genannt: ein konkreter Artikel mit eigenen Werten.

In echten Projekten steht jede Klasse in einer eigenen Datei, Artikel.java. In den Beispielen steht sie über // in main, darunter der Code, der sie benutzt.

Typische Stolperfallen

Achtung

Ein Konstruktor hat keinen Rückgabetyp, auch nicht void. Mit void Artikel(…) wäre es eine normale Methode, und new Artikel(…) mit Argumenten fände keinen passenden Konstruktor.

Achtung

Heißen Parameter und Attribut gleich, braucht es this.: this.name = name;. Ohne this weist sich der Parameter selbst zu, das Attribut bleibt leer.

Tipp

Klassen schreibt man groß (Artikel), Objekte klein (maus). Der Klassenname ist der Bauplan, die Variable das konkrete Ding.

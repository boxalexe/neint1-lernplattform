Das erste Programm: eine Bestellbestätigung

Ziel dieser Lektion

Du kennst den Aufbau eines Java-Programms (Klasse, main-Methode, Anweisungen), gibst Text mit println und print aus und weißt, was zwischen Quellcode und laufendem Programm passiert.

Szenario: Onlineshop

Ein kleiner Onlineshop für IT-Zubehör: Artikel mit Preis und Lagerbestand, ein Warenkorb, Rabatte und Versandkosten. Ab 50 Euro ist der Versand kostenlos.

Der Stoff

Der rote Faden dieses Kurses

Durch alle Lektionen zieht sich ein Onlineshop für IT-Zubehör. Er wächst mit dir: Heute gibt er eine Bestellbestätigung aus. In den nächsten Lektionen speichert er Preise und Mengen, entscheidet über Versandkosten, rechnet den Warenkorb durch, bekommt eigene Methoden und Listen und wird am Ende aus Klassen wie Artikel und Warenkorb zusammengesetzt. Daneben tauchen ein Login und ein Ticketsystem auf, weil die Prüfung auch solche Fälle gern nimmt.

In der Praxis

Jede Bestellung im Shop endet mit so einer Bestätigung, ob auf dem Bildschirm, in der E-Mail oder im Log des Servers. Konsolenausgaben sind außerdem das erste Werkzeug beim Fehlersuchen.

Vom Quellcode zur Ausführung

  1. Du schreibst den Quellcode in Bestellung.java.
  2. Der Compiler javac übersetzt ihn in Bytecode (Bestellung.class), eine plattformunabhängige Zwischensprache. Schreibfehler meldet er schon hier.
  3. Die JVM lädt den Bytecode. Ihr JIT-Compiler (Just-in-Time) übersetzt häufig genutzte Teile während des Laufs in Maschinencode der jeweiligen CPU.

So läuft dasselbe Programm auf Windows, Linux und macOS: „Write once, run anywhere“.

BegriffWas es ist
JDK (Java Development Kit)der Werkzeugkasten zum Entwickeln: Compiler javac, JVM und Standardbibliothek. Ein SDK speziell für Java

Typische Stolperfallen

Achtung

Java unterscheidet Groß- und Kleinschreibung: System mit großem S, main klein. Der Dateiname muss zum Namen der öffentlichen Klasse passen.

Tipp

Text steht in doppelten Anführungszeichen. Ein Anführungszeichen im Text selbst schreibst du als \", einen Zeilenumbruch mitten im Text als \n.

Schleifen: Warenkorb, Login-Versuche, Ticketlisten

Ziel dieser Lektion

Du kannst for-, for-each-, while- und do-while-Schleifen lesen, sie im Schreibtischtest Zeile für Zeile nachverfolgen und weißt, welche Schleife zu welcher Aufgabe passt.

Szenario: Onlineshop

Ein kleiner Onlineshop für IT-Zubehör: Artikel mit Preis und Lagerbestand, ein Warenkorb, Rabatte und Versandkosten. Ab 50 Euro ist der Versand kostenlos.

Der Stoff

Wozu Schleifen?

Bisher ging es um einen Artikel und eine Regel. Ein Warenkorb hat aber mehrere Artikel, und Software arbeitet fast immer mit vielen gleichartigen Daten: allen Artikeln im Warenkorb, allen offenen Tickets, jedem Anmeldeversuch. Eine Schleife wiederholt dieselben Anweisungen für jedes Element, statt sie hundertmal abzuschreiben. Die Prüfung kennt vier Formen, und jede hat in echter Software ihren festen Platz.

Mit Ablauf verfolgen läuft jedes Beispiel Zeile für Zeile, mit den Werten, die Java wirklich berechnet. Genau so funktioniert ein Schreibtischtest auf Papier.

for: die Warenkorbsumme

Java
1
int[] preiseInCent = {1999, 4950, 999};
Drei Artikel im Warenkorb: Funkmaus, Tastatur, USB-C-Kabel. Preise in Cent, damit keine Rundungsfehler entstehen.
2
int summeInCent = 0;
Die Summe startet bei 0. Ohne Startwert lässt Java nicht addieren.
3
for (int i = 0; i < preiseInCent.length; i++) {
Start bei Index 0, weiter solange i kleiner als die Länge (3) ist, nach jedem Durchlauf i um 1 erhöhen.
4
    summeInCent = summeInCent + preiseInCent[i];
Den Preis an Position i zur Summe addieren.
5
}
Ende des Rumpfs: Java springt zurück in den Schleifenkopf.
6
System.out.println("Zwischensumme: " + summeInCent / 100.0 + " Euro");
Erst für die Anzeige in Euro umrechnen. 100.0 statt 100, sonst würde ganzzahlig geteilt.
In der Praxis

Jeder Onlineshop rechnet so die Zwischensumme, bevor Versand und Rabatte dazukommen. Preise stehen deshalb in Datenbanken oft als ganze Cent-Beträge.

for-each: Artikel im Warenkorb zählen

Java
1
int[] mengen = {2, 1, 4};
Wie oft jeder Artikel im Warenkorb liegt.
2
int stueckGesamt = 0;
3
for (int menge : mengen) {
for-each: „für jede menge in mengen“. Kein Index nötig, Java liefert die Werte der Reihe nach.
4
    stueckGesamt += menge;
Kurzform für stueckGesamt = stueckGesamt + menge.
5
}
6
System.out.println(stueckGesamt + " Artikel im Warenkorb");
In der Praxis

Die kleine Zahl am Warenkorb-Symbol oben rechts in jedem Shop entsteht genau so. for-each ist die erste Wahl, wenn jedes Element einmal gebraucht wird und die Position egal ist.

while: Login mit begrenzten Versuchen

Java
1
String[] eingaben = {"sommer2024", "Sommer2024", "S0mmer!2024"};
Drei Passworteingaben nacheinander, wie sie ein Benutzer tippt.
2
String passwort = "S0mmer!2024";
Das richtige Passwort. In echter Software steht hier nur ein Hashwert.
3
int versuche = 0;
4
boolean angemeldet = false;
5
while (!angemeldet && versuche < 3) {
Kopfgesteuert: Vor jedem Durchlauf wird geprüft, ob noch nicht angemeldet und noch Versuche übrig sind.
6
    if (eingaben[versuche].equals(passwort)) {
Texte vergleicht man mit equals, nie mit ==.
7
        angemeldet = true;
Treffer: Beim nächsten Prüfen ist die Bedingung im Kopf falsch.
8
    }
9
    versuche++;
Ohne diese Zeile wäre die Schleife endlos, falls das Passwort nie stimmt.
10
}
11
if (angemeldet) {
12
    System.out.println("Angemeldet nach " + versuche + " Versuchen");
13
} else {
14
    System.out.println("Konto gesperrt");
15
}
In der Praxis

Banking-Apps, Firmen-Logins und Router sperren nach wenigen Fehlversuchen. Die Grenze bremst Angreifer, die Passwörter automatisch durchprobieren (Brute Force).

do-while: eine Eingabe mindestens einmal verarbeiten

Java
1
String[] befehle = {"status 502", "status 504", "ende"};
Befehle, die ein Techniker nacheinander in ein Konsolenwerkzeug des Ticketsystems tippt.
2
int nr = 0;
3
String befehl = "";
Startwert: Die Variable existiert schon vor der Schleife, weil die Bedingung unten sie braucht.
4
do {
Fußgesteuert: Der Rumpf läuft mindestens einmal, geprüft wird erst unten.
5
    befehl = befehle[nr];
6
    System.out.println("> " + befehl);
7
    nr++;
8
} while (!befehl.equals("ende"));
Erst nach dem Durchlauf prüfen: Bei "ende" ist Schluss.
9
System.out.println("Sitzung beendet nach " + nr + " Befehlen");
In der Praxis

Konsolenprogramme und Menüs an Kassen oder Terminals zeigen ihre Auswahl immer mindestens einmal. Erst die Eingabe entscheidet, ob es weitergeht.

continue und break: Tickets filtern, Suche abbrechen

Java
1
int[] prioritaeten = {3, 1, 4, 2};
Prioritäten der Tickets 501 bis 504 (1 = kritisch).
2
String[] status = {"offen", "in Arbeit", "erledigt", "offen"};
3
int dringend = -1;
-1 heißt: noch nichts gefunden. Ein gültiger Index ist nie negativ.
4
for (int i = 0; i < status.length; i++) {
5
    if (status[i].equals("erledigt")) {
6
        continue;
Erledigte Tickets überspringen: weiter mit dem nächsten Durchlauf.
7
    }
8
    if (prioritaeten[i] <= 2) {
9
        dringend = i;
10
        break;
Das erste dringende Ticket ist gefunden: Schleife sofort verlassen.
11
    }
12
}
13
System.out.println("Zuerst bearbeiten: Ticket " + (501 + dringend));
Aus dem Index wird die Ticketnummer.
In der Praxis

Ein Service-Desk zeigt oben das dringendste offene Ticket. Erledigtes fällt heraus, und die Suche endet beim ersten Treffer, statt die ganze Liste zu prüfen.

Welche Schleife wann?

SchleifeWannBeispiel aus der Praxis
forAnzahl der Durchläufe steht vorher fest, der Index wird gebrauchtPreis an Position i mit Menge an Position i verrechnen
for-eachjedes Element einmal, Position egalArtikel im Warenkorb zählen
whileEnde hängt von einem Ereignis ab, eventuell gar kein DurchlaufLogin-Versuche, bis Erfolg oder Sperre
do-whilemindestens ein Durchlauf, Prüfung danachMenü anzeigen, bis „ende“ eingegeben wird

Typische Stolperfallen

Achtung

Off-by-one-Fehler: i <= preise.length läuft einmal zu oft. Den Index preise.length gibt es nicht, Java bricht mit ArrayIndexOutOfBoundsException ab. Bei Arrays gilt immer i < länge.

Achtung

Endlosschleife: Ändert der Rumpf nichts an der Bedingung, etwa weil versuche++ fehlt, läuft die Schleife ewig. Die Anwendung hängt, der Lüfter dreht hoch.

Tipp

Geld in ganzen Cent statt double: 0.1 + 0.2 ergibt mit double 0.30000000000000004. Mehr dazu in der Lektion zu Datentypen.

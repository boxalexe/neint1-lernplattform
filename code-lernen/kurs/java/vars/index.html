Variablen und Datentypen

Ziel dieser Lektion

Du kannst Werte speichern, benennen und wieder verwenden und weißt, welche Arten von Werten es gibt.

Die Idee dahinter

Die Schachtel mit Etikett

Eine Variable ist wie eine Schachtel mit einem Etikett. Das Etikett ist der Name (z. B. alter), der Inhalt ist der Wert (z. B. 25). Du kannst jederzeit nachsehen, was in der Schachtel liegt, oder den Inhalt austauschen. Das Programm „merkt“ sich so Dinge zwischen zwei Anweisungen.

Zuweisung heißt: reinlegen, nicht vergleichen

Das Zeichen = bedeutet in fast allen Programmiersprachen „lege den Wert rechts in die Variable links“. Es ist keine mathematische Gleichung. Darum ist zähler = zähler + 1 völlig in Ordnung: Erst wird rechts gerechnet (alter Wert plus 1), dann wird das Ergebnis wieder in dieselbe Schachtel gelegt.

Datentypen

Jeder Wert hat einen Typ. Der Typ bestimmt, was man damit tun darf: Zahlen kann man addieren, Texte aneinanderhängen, Wahrheitswerte mit UND/ODER verknüpfen. Die Zahl 5 und der Text "5" sind nicht dasselbe.

DatentypWas drinstecktBeispiele
Ganze ZahlZahlen ohne Komma0, 42, -7
KommazahlZahlen mit Nachkommastellen (mit Punkt geschrieben)3.14, 0.5
Text (String)Zeichenketten, in Anführungszeichen"Hallo", "abc123"
Wahrheitswert (Boolean)Nur zwei MöglichkeitenWAHR / FALSCH (true / false)

Gute Namen

Wähle Namen, die sagen, was drinsteckt: preis statt x. Du liest Code viel öfter, als du ihn schreibst. Namen enthalten keine Leerzeichen und beginnen nicht mit einer Ziffer.

In Java

Variablen mit festem Typ

Java

int alter = 25;
Typ Name = Wert. int ist eine ganze Zahl. Der Typ steht immer vor dem Namen.
2

double für Kommazahlen, mit Punkt geschrieben.
3
String name = "Ada";
String (großes S!) ist Text, in doppelten Anführungszeichen.
4

boolean: nur true oder false.
5

char ist ein Zeichen, in einfachen Anführungszeichen.

Neu zuweisen: ohne Typ, denn die Variable gibt es schon. Jetzt 26.
7
System.out.println(name + " ist " + alter);
Mit + hängst du Text und Werte aneinander (String-Verkettung, auch Konkatenation): Ada ist 26

Die acht primitiven Datentypen

Daneben gibt es die komplexen Datentypen (Referenztypen): jede Klasse, allen voran String. String ist also kein primitiver Typ. Standardwerte bekommen nur Attribute; eine lokale Variable musst du selbst setzen, bevor du sie liest, sonst meldet der Compiler einen Fehler.

Deklarieren, initialisieren, Literale

Java
1
int punkte;
Deklaration: Typ und Name, noch kein Wert.
2
punkte = 42;
Erste Zuweisung. 42 ist ein Literal: ein Wert, der direkt im Code steht.
3
int level = 1;
Deklaration und erster Wert in einem Schritt: Initialisierung.
4
long menschen = 8_100_000_000L;
Über etwa 2,1 Milliarden passt nur long. Das L macht das Literal zum long, die Unterstriche dienen nur der Lesbarkeit.
5
float faktor = 1.5F;
Kommazahl-Literale sind automatisch double. Für float braucht es ein F am Ende.

Casten: Typen umwandeln

Java
1
int ganz = 1234567890;
Eine große ganze Zahl.
2
double d = ganz;
Impliziter Cast: von klein nach groß geht automatisch, es geht nichts verloren.
3
short s = (short) ganz;
Expliziter Cast: von groß nach klein musst du ausdrücklich verlangen. Hier passen nicht alle Bits hinein, s ist 722.
4
int abgeschnitten = (int) 3.99;
Kommazahl zu int schneidet ab, es wird nicht gerundet: 3.
5
double schnitt = (double) 7 / 2;
Erst wird 7 zum double, dann geteilt: 3.5 statt 3.

Casten geht nur zwischen verträglichen Typen, also Zahl zu Zahl. Text in eine Zahl zu verwandeln ist kein Cast, sondern Parsen mit Integer.parseInt (siehe unten).

Eingabe umwandeln und formatiert ausgeben (EVA-Prinzip)

Java
1
// Eingabe
EVA: Eingabe. Was über die Tastatur kommt, ist immer erst Text.
2
System.out.print("Tag: ");
3
int tag = Integer.parseInt(sc.nextLine());
Parsen: Der Text "7" wird zur Zahl 7. Das Zeichen '7' ist intern nämlich der Code 55, nicht die Zahl 7.
4
System.out.print("Monat: ");
5
int monat = Integer.parseInt(sc.nextLine());
6
double breite = Double.parseDouble("2.5");
Für Kommazahlen gibt es Double.parseDouble, mit Punkt geschrieben. Steht dort "abc", gibt es eine NumberFormatException.
7
// Verarbeitung
EVA: rechnen, vergleichen, zusammensetzen.
8
String datum = String.format("%02d.%02d.", tag, monat);
%02d heißt: ganze Zahl, mindestens zwei Stellen, vorne mit 0 auffüllen. Aus 7 wird 07.
9
// Ausgabe
EVA: das Ergebnis in verständlicher Form.
10
System.out.println("Datum: " + datum);
Bei Tag 10 und Monat 7 steht hier: Datum: 10.07.

Integer und Double sind Wrapperklassen: Zu jedem einfachen Datentyp gibt es eine Klasse mit Hilfsmethoden wie parseInt. Weitere sind Long, Float, Boolean und Character.

Typische Stolperfallen

Achtung

Zuweisung ist nicht Gleichheit. In den meisten Sprachen ist = die Zuweisung und == der Vergleich. Wer in einer Bedingung = statt == schreibt, macht einen der häufigsten Anfängerfehler.

Achtung

Eine Variable muss einen Wert haben, bevor du sie benutzt. Sonst gibt es einen Fehler oder (in C) zufälligen Müll.

Achtung

Du kannst einer int-Variable keinen Text zuweisen: int x = "5"; ist ein Fehler beim Übersetzen. Das ist gewollt: Der Compiler schützt dich.

Tipp

Variablen und Methoden schreibt man in camelCase (istStudent), Klassen mit großem Anfang (Konto).

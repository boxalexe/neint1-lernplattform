Standardalgorithmen: Summe, Maximum, Suche, Zählen, Sortieren

Ziel dieser Lektion

Du programmierst die vier Standardalgorithmen der Prüfung (Summe, Maximum, lineare Suche, Zählen), sortierst mit Bubble Sort und verstehst Rekursion mit Abbruchbedingung.

Szenario: Onlineshop

Ein kleiner Onlineshop für IT-Zubehör: Artikel mit Preis und Lagerbestand, ein Warenkorb, Rabatte und Versandkosten. Ab 50 Euro ist der Versand kostenlos.

Der Stoff

Vier Muster, die immer wieder kommen

Summe, Maximum, lineare Suche und Zählen stecken in fast jeder Prüfungsaufgabe, oft gut versteckt: „Ermitteln Sie den teuersten Artikel“, „Wie viele Tickets sind offen?“. Das Muster ist immer gleich: Startwert vor der Schleife, Vergleich oder Rechnung in der Schleife, Ergebnis danach.

In der Praxis

Umsatz des Tages, teuerster Artikel, Anzahl günstiger Artikel: Ein einziger Durchlauf durch die Liste reicht für alle drei. Berichte im Shop rechnen genau so.

Sortieren mit Bubble Sort

Beim Bubble Sort vergleichst du immer zwei Nachbarn und tauschst sie, wenn sie falsch herum stehen. Nach jeder Runde ist das größte Element ganz hinten „aufgestiegen“ wie eine Blase. Zum Tauschen braucht es eine Hilfsvariable, sonst geht ein Wert verloren.

In der Praxis

„Nach Preis sortieren“ im Shop nutzt kein Bubble Sort, sondern schnellere Verfahren. In der Prüfung ist Bubble Sort trotzdem Standard, weil man ihn von Hand durchspielen kann.

Rekursion

Eine Funktion darf sich selbst aufrufen, mit einem kleineren Problem, bis ein einfacher Fall erreicht ist. Das heißt Rekursion. Ohne Abbruchbedingung ruft sie sich ewig auf. Im Ablauf siehst du für jeden Aufruf einen eigenen Kasten mit seinen Variablen, so werden die wartenden Aufrufe sichtbar.

AUSGABE summeBis(4)
In der Praxis

Rekursion steckt überall, wo etwas in sich selbst verschachtelt ist: Ordner mit Unterordnern, Kategorien mit Unterkategorien im Shop, Kommentare mit Antworten.

Typische Stolperfallen

Achtung

Maximum und Minimum nie mit 0 starten. Beim Minimum über lauter positive Preise bliebe die 0 stehen, obwohl sie gar nicht in der Liste ist.

Tipp

Beim Tauschen immer drei Schritte mit Hilfsvariable. a <- b gefolgt von b <- a überschreibt a, bevor es gesichert ist.

Prüfe dich

  1. Warum startet die lineare Suche mit position <- -1?
    • Die lineare Suche beginnt immer am Ende der Liste
    • -1 kommt als Index nie vor und heißt „nicht gefunden“
    • -1 ist immer der Index des letzten Elements
    • Weil der Index 0 im Pseudocode verboten ist
  2. Wozu braucht Bubble Sort beim Tauschen eine Hilfsvariable?
    • Damit sich der Index erhöht
    • Weil Listen nicht verändert werden dürfen
    • Damit weniger Runden nötig sind
    • Damit beim Überschreiben kein Wert verloren geht
  3. Was darf bei einer rekursiven Funktion nie fehlen?
    • Eine globale Variable
    • Eine Abbruchbedingung
    • Eine äußere Schleife
    • Eine AUSGABE

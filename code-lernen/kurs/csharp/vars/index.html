Variablen und Datentypen

Ziel dieser Lektion

Du kannst Werte speichern, benennen und wieder verwenden und weißt, welche Arten von Werten es gibt.

Die Idee dahinter

Die Schachtel mit Etikett

Eine Variable ist wie eine Schachtel mit einem Etikett. Das Etikett ist der Name (z. B. alter), der Inhalt ist der Wert (z. B. 25). Du kannst jederzeit nachsehen, was in der Schachtel liegt, oder den Inhalt austauschen. Das Programm „merkt“ sich so Dinge zwischen zwei Anweisungen.

Zuweisung heißt: reinlegen, nicht vergleichen

Das Zeichen = bedeutet in fast allen Programmiersprachen „lege den Wert rechts in die Variable links“. Es ist keine mathematische Gleichung. Darum ist zähler = zähler + 1 völlig in Ordnung: Erst wird rechts gerechnet (alter Wert plus 1), dann wird das Ergebnis wieder in dieselbe Schachtel gelegt.

Datentypen

Jeder Wert hat einen Typ. Der Typ bestimmt, was man damit tun darf: Zahlen kann man addieren, Texte aneinanderhängen, Wahrheitswerte mit UND/ODER verknüpfen. Die Zahl 5 und der Text "5" sind nicht dasselbe.

DatentypWas drinstecktBeispiele
Ganze ZahlZahlen ohne Komma0, 42, -7
KommazahlZahlen mit Nachkommastellen (mit Punkt geschrieben)3.14, 0.5
Text (String)Zeichenketten, in Anführungszeichen"Hallo", "abc123"
Wahrheitswert (Boolean)Nur zwei MöglichkeitenWAHR / FALSCH (true / false)

Gute Namen

Wähle Namen, die sagen, was drinsteckt: preis statt x. Du liest Code viel öfter, als du ihn schreibst. Namen enthalten keine Leerzeichen und beginnen nicht mit einer Ziffer.

In C#

Variablen mit festem Typ

C#
1
int alter = 25;
Typ Name = Wert. int ist eine ganze Zahl.
2
double preis = 19.99;
double für Kommazahlen, Punkt als Trenner.
3
string name = "Ada";
string (klein!) ist Text in doppelten Anführungszeichen.
4
bool istStudent = true;
bool: nur true oder false (klein).
5
char buchstabe = 'A';
char ist ein Zeichen in einfachen Anführungszeichen.
6
alter = alter + 1;
Neu zuweisen: ohne Typ. Jetzt 26.
7
Console.WriteLine($"{name} ist {alter}");
Das $ vor dem Text macht eine Interpolation: Was in {} steht, wird eingesetzt. Ausgabe: Ada ist 26

var, Konstanten und Umwandlungen

C#
1
var zahl = 42;
var lässt C# den Typ erkennen (int). Er bleibt trotzdem fest.
2
const int MaxPunkte = 100;
const: Konstante, nicht mehr änderbar.
3
int ergebnis = int.Parse("25");
Wandelt Text in eine Zahl um. Bei ungültigem Text gibt es einen Fehler.
4
bool ok = int.TryParse("abc", out int wert);
TryParse versucht es und liefert true/false. Bei Misserfolg ist wert 0.
5
string text = 25.ToString();
Wandelt eine Zahl in Text um.

Typische Stolperfallen

Achtung

Zuweisung ist nicht Gleichheit. In den meisten Sprachen ist = die Zuweisung und == der Vergleich. Wer in einer Bedingung = statt == schreibt, macht einen der häufigsten Anfängerfehler.

Achtung

Eine Variable muss einen Wert haben, bevor du sie benutzt. Sonst gibt es einen Fehler oder (in C) zufälligen Müll.

Achtung

int x = "5"; ist ein Fehler beim Übersetzen: Der Compiler lässt keinen Text in einer Zahl-Variable zu. Und String oder string sind dasselbe, üblich ist string.

Prüfe dich

  1. Was passiert bei zähler = zähler + 1?
    • zähler wird auf 1 gesetzt
    • Der Computer vergleicht zähler mit zähler + 1
    • Das ist ein Fehler, weil eine Zahl nicht gleich sich plus 1 sein kann
    • Der Wert von zähler wird um 1 größer
  2. Welcher Typ passt zum Wert "42" (mit Anführungszeichen)?
    • Text
    • Ganze Zahl
    • Kommazahl
    • Wahrheitswert
  3. Was macht das $ in $"Hallo {name}"?
    • Es macht den Text zu Geld
    • Es setzt Werte in den Text ein
    • Es kommentiert den Text aus
    • Es wandelt in eine Zahl um

Vertiefung: Schnittstellen und LINQ

Ziel dieser Lektion

Du kennst Schnittstellen in C# und kannst einfache LINQ-Abfragen lesen.

Der Stoff

Schnittstellen (interface)

Eine Schnittstelle legt fest, was eine Klasse können muss. Namen beginnen in C# üblicherweise mit I.

Eine Schnittstelle umsetzen

1
interface IZahlungsart {
Schnittstelle, Name mit I am Anfang.

    bool Bezahlen(double betrag);
Wer sie umsetzt, muss diese Methode anbieten.

}

LINQ

LINQ ist eine Sammlung von Methoden, mit denen du Listen abfragen kannst: filtern, sortieren, umwandeln. Ähnlich wie SQL, nur direkt im Code. Das x => … ist ein Lambda: eine kurze namenlose Funktion.

LINQ: Where, Select, Sum

C#
1
using System.Linq;
Holt die LINQ-Methoden (in neuen Projekten oft automatisch da).
2
int[] zahlen = { 1, 2, 3, 4, 5 };
Ausgangsdaten.
3
var gerade = zahlen.Where(x => x % 2 == 0);
Where behält nur Elemente, für die das Lambda true liefert: 2 und 4.
4
var verdoppelt = gerade.Select(x => x * 2);
Select wandelt jedes Element um: 4 und 8.
5
Console.WriteLine(string.Join(", ", verdoppelt));
Join fügt alles zu einem Text zusammen: 4, 8
6
Console.WriteLine(zahlen.Sum());
Sum addiert alle: 15

Prüfe dich

  1. Wofür steht x => x * 2?
    • Eine Zuweisung: x wird zu x * 2
    • Ein Vergleich: ist x größer gleich x * 2
    • Ein Zeiger, der auf x mal 2 zeigt
    • Ein Lambda: nimm x und liefere x * 2
  2. Was macht Where in LINQ?
    • Es sucht die Position eines Elements
    • Es zählt die Elemente einer Liste
    • Es filtert Elemente nach einer Bedingung
    • Es sortiert die Elemente nach einem Schlüssel

Vertiefung: Asynchron und Webseiten steuern

Ziel dieser Lektion

Du verstehst, warum JavaScript „nebenbei“ arbeiten kann und wie man damit Webseiten verändert.

Der Stoff

Warten, ohne zu blockieren

Manches dauert: Daten aus dem Netz holen, eine Sekunde warten. JavaScript friert dabei nicht ein, sondern erledigt andere Dinge weiter und kommt später zurück. Dafür gibt es Promises und die Schreibweise async/await. await heißt: „Warte hier auf das Ergebnis, aber blockiere den Rest nicht.“

async und await

JavaScript
1
function warte(ms) {
Eine Funktion, die ein Promise liefert: ein Versprechen, dass später etwas fertig ist.
2
  return new Promise((fertig) => setTimeout(fertig, ms));
setTimeout ruft fertig nach ms Millisekunden auf.
3
}
Ende.
4
async function ablauf() {
async markiert eine Funktion, in der await erlaubt ist.
5
  console.log("Start");
Läuft sofort.
6
  await warte(500);
Pausiert diese Funktion 500 ms. Das übrige Programm läuft weiter.
7
  console.log("500 ms später");
Läuft erst nach der Pause.
8
}
Ende.
9
ablauf();
Startet den Ablauf.
10
console.log("Dieses Programm läuft einfach weiter");
Erscheint vor "500 ms später", denn ablauf() wartet nur in sich selbst.
Gut zu wissen

Dieses Beispiel hat bewusst keinen „Ausführen“-Knopf: Die Ausführungsumgebung dieser App sammelt Ausgaben nur bis zum Ende des Programms und würde die verspätete Ausgabe verpassen. Im Browser (Taste F12, dann der Reiter Konsole) oder mit Node.js läuft es wie beschrieben.

Webseiten verändern (das DOM)

Im Browser ist eine Webseite ein Baum aus Elementen, das DOM. Mit JavaScript suchst du Elemente und änderst sie, reagierst auf Klicks und baust so interaktive Seiten.

Auf Klicks reagieren

JavaScript
1
const knopf = document.querySelector("#knopf");
Sucht das Element mit der id "knopf" auf der Seite.
2
const ausgabe = document.querySelector("#ausgabe");
Sucht das Ausgabefeld.
3
let zaehler = 0;
Merkt sich, wie oft geklickt wurde.
4
knopf.addEventListener("click", () => {
Registriert eine Funktion, die bei jedem Klick läuft (ein Ereignis, englisch event).
5
  zaehler++;
Erhöht den Zähler um 1.
6
  ausgabe.textContent = "Klicks: " + zaehler;
Ändert den sichtbaren Text im Ausgabefeld.
7
});
Ende der Funktion und des Aufrufs.
Gut zu wissen

Dieses Beispiel braucht eine echte Webseite mit <button id="knopf"> und <p id="ausgabe">. Probiere es in einer eigenen HTML-Datei aus.

Prüfe dich

  1. Was bewirkt await in einer async-Funktion?
    • Die Funktion wartet auf das Ergebnis, ohne das restliche Programm zu blockieren
    • Das ganze Programm hält an, bis das Ergebnis da ist, auch die Oberfläche
    • Die Funktion wird parallel ein zweites Mal gestartet
    • Ein Fehler im Ergebnis wird abgefangen und ignoriert
  2. Wofür steht „DOM“ im Browser?
    • Die Datenbank, in der der Browser Cookies ablegt
    • Der Baum aus Elementen, aus dem eine Webseite besteht
    • Die Liste aller Fehler, die die Konsole meldet
    • Die Skriptsprache, in der Webseiten geschrieben werden

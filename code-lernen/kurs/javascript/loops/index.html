Schleifen: Warenkorb, Login-Versuche, Ticketlisten

Ziel dieser Lektion

Du wählst sicher zwischen for, while, do…while und for…of, steuerst Durchläufe mit break und continue und vermeidest Off-by-one-Fehler.

Szenario: Onlineshop

Ein kleiner Onlineshop für IT-Zubehör: Artikel mit Preis und Lagerbestand, ein Warenkorb, Rabatte und Versandkosten. Ab 50 Euro ist der Versand kostenlos.

Der Stoff

Vier Schleifen, vier Einsatzfälle

Eine Schleife wiederholt einen Block, bis eine Bedingung nicht mehr stimmt. In JavaScript nutzt du im Alltag vor allem for…of (für alle Elemente eines Arrays), for (wenn du den Index brauchst) und while (wenn erst zur Laufzeit klar ist, wann Schluss ist).

for…of: Warenkorb summieren

JavaScript
1
const preise = [1999, 999, 3490];
2
let summe = 0;
3
for (const preis of preise) {
for…of geht jedes Element sauber ohne Index durch.
4
  summe += preis;
5
}
6
console.log("Warenkorb:", summe, "Cent");
In der Praxis

Sobald du keinen Index brauchst, ist for…of die sicherste Schleife: kein Off-by-one-Fehler möglich.

2

3
while (i < eingaben.length && i < 3) {
Kopfgesteuert: prüft vor jedem Versuch.
4
  if (eingaben[i] === "Sommer2024!") {
5

6
    break;
break verlässt die Schleife sofort.
7
  }
8
  i++;
Zähler erhöhen – ohne diese Zeile entsteht eine Endlosschleife!
9
}
In der Praxis

Bei Login-Prüfungen oder Wiederholungen nach Netzwerkfehlern ist vorher nicht bekannt, welcher Versuch klappt – genau dafür gibt es while.

for mit Index und continue: ausverkaufte Artikel überspringen

JavaScript
1
const bestaende = [35, 0, 14, 0, 8];
2
let lieferbar = 0;
3
for (let i = 0; i < bestaende.length; i++) {
Index läuft von 0 bis length - 1 (<, nicht <=!).
4
  if (bestaende[i] === 0) continue;
continue überspringt den Rest dieses Durchlaufs.
5
  lieferbar++;
6
}
7
console.log("Lieferbare Artikel:", lieferbar);
In der Praxis

Im Shop-Katalog filtert genau dieses Muster ausverkaufte Ware heraus oder zählt, wie viele Produkte sofort versendbar sind.

Typische Stolperfallen

Achtung

Bei for (let i = 0; i <= arr.length; i++) ist arr[arr.length] in JavaScript undefined – ein Off-by-one-Fehler, der beim Rechnen zu NaN führt! Immer < arr.length.

Prüfe dich

  1. Welche Schleife wählst du am besten, um alle Artikelpreise eines Arrays ohne Index zu summieren?
    • for (const p of preise)
    • do … while (false)
    • while (true)
    • switch (preise)
  2. Was bewirkt continue; mitten in einer Schleife?
    • Es beendet die gesamte Schleife sofort und springt dahinter
    • Es setzt den Schleifenzähler wieder zurück auf 0
    • Es startet das gesamte Programm von vorne
    • Es bricht nur den aktuellen Durchlauf ab und startet den nächsten
  3. Wie oft läuft for (let i = 0; i < 4; i++)?
    • 5-mal (i = 0, 1, 2, 3, 4)
    • 3-mal (i = 0, 1, 2)
    • Unendlich oft
    • 4-mal (i = 0, 1, 2, 3)

Arrays, Objekte und die vier Standardalgorithmen

Ziel dieser Lektion

Du verwaltest Artikel und Tickets in Arrays und Objekten, setzt die vier IHK-Standardalgorithmen (Summieren, Filtern/Zählen, Min/Max, Suchen) um und nutzt map, filter und reduce.

Szenario: Onlineshop

Ein kleiner Onlineshop für IT-Zubehör: Artikel mit Preis und Lagerbestand, ein Warenkorb, Rabatte und Versandkosten. Ab 50 Euro ist der Versand kostenlos.

Der Stoff

Die vier IHK-Kernmuster an echten Daten

Ob Warenkorb, Lagerliste oder Service-Desk: Fast jede Prüfungsaufgabe zu Listen baut auf denselben vier Mustern auf – Summieren, Filtern/Zählen, Minimum/Maximum finden und Suchen (lineare Suche). In JavaScript kombinierst du dazu Arrays ([...]) mit Objekten ({ name: "Funkmaus", preis: 1999 }).

Typische Stolperfallen

Achtung

Beim Minimum-Suchen niemals mit let min = 0; starten – sonst bleibt min bei positiven Preisen für immer 0! Immer mit liste[0] starten.

Prüfe dich

  1. Warum startet man beim Suchen des günstigsten Preises mit let min = preise[0]; statt mit 0?
    • Weil Arrays in JavaScript keine 0 enthalten dürfen
    • Weil kein positiver Preis kleiner als 0 ist und min sonst 0 bliebe
    • Weil 0 in JavaScript kein gültiger Datentyp number ist
    • Weil preise[0] automatisch immer der kleinste Wert ist
  2. Was liefert tickets.filter((t) => t.prio === 1)?
    • Ein neues Array mit allen Tickets der Priorität 1
    • Nur das erste Ticket mit Priorität 1 als Objekt
    • Die Anzahl der Tickets mit Priorität 1 als Zahl
    • Verändert das bestehende Array ohne Rückgabewert
  3. Woran erkennst du, dass arr.length kein Methodenaufruf ist?
    • Es stehen keine Klammern dahinter
    • Es beginnt mit einem Großbuchstaben
    • Es steht immer hinter einem return
    • Es liefert immer true oder false

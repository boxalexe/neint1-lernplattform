Vererbung

Ziel dieser Lektion

Du verstehst die „ist-ein“-Beziehung, kannst Vererbung im UML lesen und kennst das Überschreiben von Methoden.

Der Stoff

Gemeinsames nur einmal schreiben

Hund und Katze haben viel gemeinsam: Beide haben einen Namen, beide können essen. Statt das zweimal zu schreiben, gibt es eine Oberklasse Tier mit dem Gemeinsamen. Hund und Katze sind Unterklassen: Sie erben alles von Tier und ergänzen nur ihr Eigenes. Der Test heißt „ist-ein“: Ein Hund ist ein Tier.

Vererbung in UML

Der Pfeil mit der hohlen Spitze zeigt von der Unterklasse zur Oberklasse: „Hund erbt von Tier“. # bedeutet geschützt: Unterklassen dürfen name nutzen, Fremde nicht.

Überschreiben

Eine Unterklasse darf eine geerbte Methode neu schreiben. laut() gibt bei einem allgemeinen Tier vielleicht nichts Besonderes zurück, bei Hund „Wau“, bei Katze „Miau“. Das nennt man Überschreiben (override).

Vorsicht, nicht alles ist Vererbung

FragePrüfe mitBeispiel
Ist es Vererbung?„ist-ein“Ein Hund ist ein Tier. Ja.
Ist es Vererbung?„ist-ein“Ein Auto ist ein Motor? Nein. Ein Auto hat einen Motor (Komposition).

Was wird vererbt, was nicht?

Die Unterklasse erbt alle Member der Oberklasse, mit einer Ausnahme: Konstruktoren werden nicht vererbt. Jede Klasse hat ihre eigenen; der Konstruktor der Unterklasse ruft den der Oberklasse auf (in Java mit super(...)). Im Diagramm wiederholst du geerbte Member in der Unterklasse nicht, außer sie werden dort überschrieben oder waren in der Oberklasse abstrakt.

Die Beziehung ist nicht umkehrbar: Jeder PKW ist ein Fahrzeug, aber nicht jedes Fahrzeug ist ein PKW.

Typische Stolperfallen

Achtung

Vererbung ist keine Abkürzung zum Code-Teilen. Erbe nur, wenn es wirklich ein „ist-ein“ ist. Sonst baust du Konstrukte, die später schwer zu ändern sind.

Prüfe dich

  1. Welche Member erbt eine Unterklasse nicht?
    • Die statischen Methoden
    • Die Konstruktoren
    • Die geschützten Attribute
    • Die öffentlichen Methoden
  2. Welcher Pfeil bedeutet Vererbung im Klassendiagramm?
    • Gestrichelte Linie mit offener Pfeilspitze
    • Gestrichelte Linie mit hohler dreieckiger Spitze
    • Durchgezogene Linie mit gefülltem Rhombus
    • Durchgezogene Linie mit hohler dreieckiger Spitze
  3. Welche Member zeichnest du in einer Unterklasse ein?
    • Nur die geerbten Attribute
    • Nur eigene und überschriebene
    • Alle geerbten und eigenen
    • Nur Konstruktoren der Oberklasse
  4. Was bedeutet {final} an einer Klasse?
    • Ihre Attribute sind alle konstant
    • Von ihr gibt es keine Objekte
    • Von ihr darf keine Klasse erben
    • Sie hat nur statische Methoden
  5. Welche Beziehung passt: „Ein Kreis ___ eine Form“?
    • nutzt eine (Abhängigkeit)
    • hat eine (Komposition)
    • ist eine (Vererbung)
    • kennt eine (Assoziation)
  6. Was bedeutet Überschreiben einer Methode?
    • Die Oberklasse löscht eine Methode, die sie vorher vererbt hat
    • Der Aufruf einer Methode wird zur Laufzeit übersprungen
    • Eine Klasse hat mehrere Methoden gleichen Namens mit anderen Parametern
    • Die Unterklasse ersetzt die geerbte Methode durch eigenes Verhalten
